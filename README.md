# ❤️ DatingApp 2025

## Full Stack Social Platform

> A modern full-stack social platform built with ASP.NET Core and Angular, focused on secure authentication, scalable architecture and responsive user experience.

![DatingApp Banner](./screenshots/banner.png)

---

## 📌 Overview

DatingApp is a full-stack web application developed to demonstrate modern software engineering practices using a clean client-server architecture.

The project implements authentication, user management, member profiles and a responsive user interface consuming a RESTful API.

This project represents the evolution of my experience building applications with backend services, frontend frameworks and database integration.

---

## 🚀 Features

- User registration and authentication
- JWT based security
- Member listing
- Member profile details
- User photos management
- Responsive UI
- REST API communication
- Protected routes
- Client-side state management
- Entity Framework Core integration

## ⚙️ Installation

### Clone repository

```bash
git clone https://github.com/aaguerrero/datingapp-2025.git
```

### Backend

```bash
cd API

dotnet restore

dotnet run
```

### Frontend

```bash
cd client

npm install

ng serve
```
